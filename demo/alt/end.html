STRATA

Layer-by-layer point-in-time checking of ML pipelines written by coding agents

output on D  =  output on D as of t

Five layers, one rule

task, features, model, in-context examples, agent. STRATA runs each on the data as it is and as it was at t, and compares.

Verdicts

LEAK + witnessCLEAN at tested timesUNCHECKABLEERROR

Get started

pip install -e .
strata init --data csvs/ --out schema.json
strata check features --schema schema.json \
    --program feats.py:get_features --entity product

For coding agents

Exit codes 0, 1, 2, 3 and a JSON witness make every check a gate. Drop SKILL.md into the agent's skills and it runs the check before reporting a score.
